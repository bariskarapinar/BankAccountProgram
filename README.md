# Bank Account Program

This project is currently in progress.

It is a simple Android application that simulates basic bank account operations like depositing and withdrawing money. It also tracks transaction history and displays the final balance to the user.

The project is built using Kotlin and follows modern Android development practices. It includes a custom `BankAccount` class to manage logic and a `MainActivity` to provide a user-friendly interface.

### Features
* **Structured Transactions**: Each transaction now includes a type, amount, timestamp, and the resulting balance.
* **Input Validation**: Deposits and withdrawals are validated to ensure valid amounts and sufficient funds.
* **Improved UI**: The transaction history now displays detailed information including when each action occurred.
